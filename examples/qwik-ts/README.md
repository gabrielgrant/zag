# Zag Qwik Examples

Qwik v2 examples for Zag machines, using Qwik Router's scaffolded SSR entrypoints and directory-based routes.

The menu example lives at `src/routes/menu/basic/index.tsx` and is served at `/menu/basic`.

```bash
pnpm dev
```

Run the Qwik Playwright target from the workspace root:

```bash
pnpm e2e-qwik
```
